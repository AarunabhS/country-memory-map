# Execution plans

Material changes use a short plan containing the impact assessment from `../DEVELOPMENT_PROTOCOL.md`, acceptance criteria, ordered implementation, verification, rollback, and unresolved decisions.

- `active/` contains work in progress. Update it when scope or evidence changes.
- `completed/` contains finished plans with actual checks and outcome.

A completed plan is evidence of execution, not proof of production deployment. Small mechanical changes may keep the assessment in the task/PR instead of creating a file when traceability is equivalent.
