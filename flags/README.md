# Flag assets

The playable SVGs in this directory are the 195 ISO alpha-2 assets used by the flag games. They are self-hosted so gameplay does not depend on a remote image request. The files retain their source SVG `viewBox` proportions; the application’s `FlagComponent` contains them in a reserved frame without stretching.

The renders are from [hampusborgos/country-flags](https://github.com/hampusborgos/country-flags), whose source files are taken from Wikimedia Commons and whose README documents the public-domain status of national flags and possible local restrictions. The upstream repository and its attribution should be retained when these assets are updated.
